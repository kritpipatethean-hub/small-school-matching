# ระบบคัดกรองการจับคู่โรงเรียนขนาดเล็ก ระดับเขตพื้นที่การศึกษาประถมศึกษา (สพป.)

ระบบนี้จับคู่โรงเรียนขนาดเล็กกับโรงเรียนคุณภาพชุมชนที่ใกล้ที่สุดภายในระยะ 10 กม. ตามถนน (แผนใช้โรงเรียนคุณภาพชุมชนเป็นศูนย์กลางการควบรวม) ทีละ สพป. โดยใช้ QGIS และปลั๊กอิน QNEAT3 แล้วสร้างแผนที่ PDF และพอร์ทัลเว็บแบบออฟไลน์

งานนี้อยู่ภายใต้โครงการจัดทำข้อมูลและวิเคราะห์สถานการณ์เพื่อเพิ่มความเสมอภาคทางการศึกษาสำหรับโรงเรียนขนาดเล็ก จัดทำโดยศูนย์บริการวิชาการเศรษฐศาสตร์ (ERTC) มหาวิทยาลัยธรรมศาสตร์

> ผลจากระบบเป็นเครื่องมือคัดกรองเบื้องต้น ไม่ใช่นโยบาย แผน หรือข้อสั่งการของ สพฐ. และไม่ใช่ข้อเสนอให้ยุบ รวม หรือเลิกสถานศึกษาแห่งใด การตัดสินใจจริงต้องพิจารณาความจุ การเดินทาง ภูมิประเทศ และความพร้อมของชุมชนร่วมด้วย

## ดูผลทันที (ไม่ต้องติดตั้งอะไร)

**เปิดพอร์ทัลออนไลน์:** https://kritpipatethean-hub.github.io/small-school-matching/ (เปิดได้ทั้งคอมพิวเตอร์และมือถือ)

หรือดาวน์โหลดไปเปิดในเครื่อง:

1. ดาวน์โหลด repo: กดปุ่ม **Code → Download ZIP** แล้วแตกไฟล์ หรือใช้ `git clone`
2. เปิด `05 พอร์ทัลส่งมอบ สพฐ/index.html` ด้วยเบราว์เซอร์ พอร์ทัลทำงานแบบออฟไลน์ ไม่ต่ออินเทอร์เน็ต
3. ตอนนี้มีผลพร้อมดู 6 พื้นที่ ได้แก่ อ่างทอง, กาญจนบุรี เขต 1, หนองคาย เขต 1, เชียงราย เขต 1, ระยอง เขต 1 และระยอง เขต 2

ถ้าชื่อไฟล์ภาษาไทยเพี้ยนหลังแตกไฟล์ ZIP ให้ใช้ 7-Zip หรือ `git clone` แทน

## ใช้งานระบบแบบเดียวกับผู้พัฒนา (Windows)

1. ติดตั้ง **QGIS 3.40.14 LTR** ไว้ที่ตำแหน่งเริ่มต้น `C:\Program Files\QGIS 3.40.14` แล้วติดตั้งปลั๊กอิน **QNEAT3** ผ่าน Plugins ของ QGIS
2. ดาวน์โหลด repo ด้วย `git clone https://github.com/kritpipatethean-hub/small-school-matching.git`
3. ดาวน์โหลดข้อมูล GIS ภายนอก 3 ไฟล์จากหน้า **Releases** ของ repo นี้ แล้วแตกไว้ในโฟลเดอร์เดียวกันที่อยู่นอกโฟลเดอร์ repo เช่น `D:\sms-gis\` (ระบบกำหนดว่าห้ามเก็บถนนทั้งประเทศไว้ใน workspace)
   - `gis_education_boundaries_spap.zip` คือขอบเขตเขตพื้นที่การศึกษา สพป.
   - `gis_osm_roads_utm47n.zip` คือถนน OpenStreetMap ทั้งประเทศ
   - `gis_admin_boundaries_tha.zip` คือขอบเขตจังหวัด อำเภอ ตำบล และเส้นขอบเขตการปกครอง
4. แก้พาธในส่วน `external_gis` ของ `04 เครื่องมือ/machine.json` ให้ชี้ไปที่ไฟล์ที่แตกไว้ โดยใช้ `\\` ใน JSON และถ้าติดตั้ง QGIS ไว้ที่อื่นให้แก้ส่วน `qgis` ด้วย ตัวอย่างเมื่อแตกไว้ที่ `D:\sms-gis\`:

   ```json
   "external_gis": {
     "education_boundaries": "D:\\sms-gis\\เขตพื้นที่การศึกษา_สพป\\เขตพื้นที่การศึกษา สพป..shp",
     "roads": "D:\\sms-gis\\GIS_OSM_Roads_Freee_ver1702_UTM47N\\GIS_OSM_Roads_Free_UTM47N.shp",
     "admin1": "D:\\sms-gis\\Subnational Administrative Boundaries\\tha_admin1.shp",
     "admin2": "D:\\sms-gis\\Subnational Administrative Boundaries\\tha_admin2.shp",
     "admin3": "D:\\sms-gis\\Subnational Administrative Boundaries\\tha_admin3.shp",
     "admin_lines": "D:\\sms-gis\\Subnational Administrative Boundaries\\tha_adminlines.shp"
   }
   ```

5. ดับเบิลคลิก `04 เครื่องมือ/รันระบบ.cmd` แล้วเลือก:
   - เมนู 1 ตรวจสถานะเครื่องและข้อมูล (ทำก่อนทุกครั้ง)
   - เมนู 2 เลือก สพป. เพื่อคำนวณ
   - เมนู 3 สร้างหรืออัปเดตพอร์ทัล
   - เมนู 4 ตรวจรับผลและพอร์ทัล (`verify`)
6. ก่อนคำนวณพื้นที่ใหม่ อ่าน `Project Tor.md` ซึ่งรวมกติกา วิธีคำนวณ สถานะพื้นที่ และข้อห้าม

เครื่องควรมี RAM ว่างอย่างน้อย 8 GB และพื้นที่ดิสก์ว่างอย่างน้อย 15 GB (กำหนดไว้ใน `machine.json`)

## สิ่งที่อยู่ใน repo

| ส่วน | เนื้อหา |
|---|---|
| `01 ข้อมูลกลาง/` | ทะเบียนโรงเรียน DMC682 (ทั้งหมดและเฉพาะโรงเรียนขนาดเล็ก) รายชื่อโรงเรียนคุณภาพชุมชน ตารางอำเภอกับ สพป. และขอบเขต สพป. ที่แก้เฉพาะกรณี |
| `02 งานรายพื้นที่/` | ผลราย สพป. ที่ตรวจรับแล้ว 6 พื้นที่ (ข้อมูล GIS แผนที่ PDF และไฟล์ตรวจคุณภาพ) และแม่แบบโครงการ QGIS |
| `04 เครื่องมือ/` | `sms_pipeline.py` (ระบบหลัก), `area_layout.py`, `areas.json` (บัญชี 183 สพป.), `machine.json` (พาธของเครื่อง) และ `รันระบบ.cmd` |
| `05 พอร์ทัลส่งมอบ สพฐ/` | พอร์ทัลเว็บแบบออฟไลน์ |
| `Project Tor.md` | กติกา โครงสร้าง สถานะปัจจุบัน และวิธีทำ ควรอ่านก่อนใช้งาน |
| `บันทึกการเปลี่ยนแปลง.md` | สรุปการเปลี่ยนแปลงรายรอบ |
| `คู่มือ QGIS ทำมือ.md` | ขั้นตอนทำด้วย QGIS GUI ใช้ตรวจผลหรือกู้กระบวนการ |

ส่วนที่ไม่ได้อยู่ใน repo: เอกสารนำเสนอและงานต้นแบบในโฟลเดอร์ `03 เอกสารต้นแบบ/`, ผลเดิมของเชียงราย เขต 2 ซึ่งยังไม่ผ่านการตรวจใหม่และห้ามเผยแพร่, และร่างแผนอนาคต ระบบหลักทำงานได้ครบโดยไม่ต้องใช้ส่วนเหล่านี้
